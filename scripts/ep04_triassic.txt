# 根拠: [21]

[解説] ここでも、地面の下が問題だったのかもしれません。地下に入り込んだマグマの年代を調べた研究では、マグマの活動は、知られている最初の噴火より、十万年ほど前に始まっていました。
# 根拠: [22]
[解説] ブラジルでは、生き物の名残を多く含む地層の中に、絶滅と同じ時期に、マグマが入り込んでいました。熱せられた地層から出たガスも、気候を変える一因になったのではないか、と考えられています。

# 根拠: [22]
[解説] {二〇二〇年|にせんにじゅうねん}の研究は、溶岩の中に閉じこめられた、小さな泡を調べ、たくさんの二酸化炭素が含まれていたことを確かめました。
[解説] 研究チームの見積もりでは、一回の噴火の波で出た二酸化炭素は、私たち人間が、今世紀のあいだに出すと見込まれている量に、匹敵します。

# ===== 9. 生き残った恐竜 =====
[転換] 陸でも、大きな入れ替わりが起きました。
[解説] あれほど多彩だった、ワニにつながる側の仲間は、ほとんどが姿を消しました。次の時代まで生き残ったのは、いまのワニにつながる、一つの枝だけでした。
# 画面: 確認
# 根拠: [25]
[溜め] 一方、恐竜は、生き残りました。そして、{次|つぎ}の時代、陸の主役の座につきます。
# 根拠: [21][26]
[転換] なぜ、恐竜だったのでしょうか。
実は、はっきりした答えは、まだありません。
[解説] {二〇二二年|にせんにじゅうにねん}に発表された研究は、寒さに注目しました。
[解説] 当時、北極に近い場所にあった、いまの中国北西部の湖の地層から、{湖|みずうみ}の氷に運ばれてきた石が、たくさん見つかったのです。暑い時代のはずなのに、北の冬は、湖が凍るほど寒かったことになります。
# 画面: 確認（湖の氷が運んだ石）／推定（その解釈）
# 根拠: [26]
[解説] この研究は、恐竜が、もともと羽毛のようなもので体を覆い、寒さに強かったのではないか、と考えました。
[解説] 巨大な噴火で空が暗くなり、厳しい寒さが何度も訪れたとき、体を覆うもののない、中くらいから大きな爬虫類たちは姿を消し、寒さに慣れていた恐竜が生き残った、と説明しています。
# 画面: 推定（説が分かれている）
# 根拠: [26]
[解説] ただし、恐竜に羽毛のようなものがあったという点は、近い親戚の化石からの推し量りです。三畳紀の恐竜そのものから、確かめられているわけではありません。
# 根拠: [26]
[解説] 一方、{二〇〇八年|にせんはちねん}の研究は、三畳紀の恐竜が、ワニの側の仲間より、特に優れていたわけではない、と指摘しています。恐竜が栄えたのは、めぐり合わせによるところが大きかったのではないか、というのです。
# 画面: 推定（説が分かれている）
# 根拠: [6]
寒さに強かったのか。それとも、運がよかったのか。その答えは、まだ出ていません。
