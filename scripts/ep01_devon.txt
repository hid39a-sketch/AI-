# ===== 1. 魚の時代 =====
[提示] デボン紀は、およそ四億二千万年前から、三億五千九百万年前まで続いた時代です。
# 根拠: [3] 国際年代層序表
恐竜が現れるのは、ここからさらに一億年以上あと。
デボン紀が始まったころ、陸の上には、まだ背の低い植物と、虫のような小さな生き物しかいませんでした。
その代わり、海には、驚くほどいろいろな魚がいました。
このため、デボン紀は「魚の時代」と呼ばれています。
いまの魚のほとんどが持っている「顎」。
食べ物をかみ切るための、この仕組みを持った魚が、一気に増えて、広がったのがこの時代でした。
# 画面: 確認
[解説] 顎のある魚そのものは、デボン紀より前から現れていますが、大きく栄えたのはこの時代です。
そして、その中で特に目立っていたのが、体の前の部分を、骨の鎧で覆った魚たちでした。

そして、その子孫の一つが、のちに陸に上がり、やがて、私たち人類につながっていきます。

# ===== 6. 海が息を止める =====
[提示] 三億七千二百万年前。
# 根拠: [3][11]
# 画面: 演出（水の色や様子は想像）
あなたは、もう一度、あの礁の前に立っています。
けれど、景色が違います。
水が、緑色に濁っています。
あれほどいた小さな魚たちが、見当たりません。
礁の壁に手を当てると、もろくなった表面が、ぼろぼろと崩れていきます。
あの巨大な礁が、崩れ始めます。
礁をつくっていた生き物たちが、次々に姿を消していきました。
これが、デボン紀の一度目の大量絶滅です。
ドイツの谷の名前から、ケルワッサー事変と呼ばれています。そこでは、二枚の黒い地層が、この出来事を記録しています。
[溜め] 黒い地層は、海の底に、酸素がほとんどなかったことを示しています。
なぜ、海から酸素が消えたのか。
一つの説は、こうです。
森から流れ込んだ栄養で、海の中の小さな藻が、爆発的に増える。
藻が死んで、海の底で腐るとき、水の中の酸素が使い果たされる。
[解説] ただし、これは有力な説の一つにすぎません。火山の噴火や、気候の急な変化を原因に挙げる研究もあり、決着はついていません。
# 画面: 推定（原因は説が分かれている）
# 根拠: [11]
どれだけの生き物が消えたのかも、研究によって数字が大きく違います。
確かなのは、海の景色をつくっていた礁が、このあと長いあいだ、元に戻らなかったということです。

# ===== 7. 最後の海 =====

# ===== 結び =====
[転換] けれど、すべてが終わったわけではありません。
生き残った者たちがいました。
サメの仲間。
そして、ひれの中に骨を持った、ティクターリクの遠い親戚たち。
[解説] ただ、ひれに骨を持つ魚たちや、四本の足を持ち始めた動物たちも、この絶滅で大きく数を減らしたと考えられています。このあとしばらくは、足を持つ動物の化石がほとんど見つからない時期とされてきました。ですが、近年、スコットランドなどで化石が次々に見つかり、その空白は埋まりつつあります。
# 画面: 推定（化石が少ない理由は、本当に数が減ったからか、化石が残りにくかったからか、議論がある）
生き残ったのは、ほんのひと握りだったのかもしれません。
もし、そのひと握りがいなかったら。
陸を歩く動物の歴史は、ここで終わっていたかもしれないのです。
空いた海を、サメの仲間が引き継ぎ、水辺では、四本の足を持つ動物たちが、少しずつ陸へと広がっていきます。
その長い道のりの先に、いま、この動画を見ているあなたがいます。
[解説] あなたの腕の中にある、肩、ひじ、手首の骨。その並び方は、三億七千五百万年前の、あの水辺の魚たちのひれに、すでに受け継がれていました。
[転換] 目を閉じて、もう一度開けてみてください。
デボン紀の海は、もうありません。
でも、その海で生き延びた者たちの続きを、あなたは、いまも生きています。
