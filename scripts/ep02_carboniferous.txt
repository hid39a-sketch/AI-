[溜め] 石炭紀の終わりごろ、それが、{二十五|にじゅうご}パーセントから、三十パーセントほどあった、という推定があります。

一つは、計算です。
植物は、光を浴びて、酸素を出します。

# ===== 6. なぜ巨大になれたのか =====
[転換] それにしても、なぜ、虫がこれほど大きくなれたのでしょうか。
いま生きているトンボの仲間で最も大きなものでも、翼を広げて二十センチに届きません。
# 画面: 確認
# 根拠: [11]
[溜め] よく言われるのが、酸素の説です。
虫には、私たちのような肺がありません。
{体じゅう|からだじゅう}に張りめぐらされた細い管を通って、空気が体の奥まで届けられます。
# 根拠: [12]
[解説] 体が大きくなるほど、この管が、体の中で占める割合も大きくなる、という研究があります。空気に酸素が多ければ、管が少なくても、体の奥まで酸素が届きます。そのため、大きな体を持てたのではないか、という説です。
# 画面: 推定
[解説] 化石の虫の大きさを一万点以上調べた研究では、最も大きな虫の大きさは、長いあいだ、空気の酸素の量と一緒に、上がったり下がったりしていました。
# 根拠: [13]
[転換] ただし、この説には、反論もあります。
[解説] 同じ研究によると、およそ一億数千万年前、鳥が上手に飛ぶようになったころから、虫の大きさは、酸素が増えても大きくならなくなりました。空飛ぶ{捕食者|ほしょくしゃ}の登場が、虫の大きさをおさえた、というのです。
# 画面: 推定
# 根拠: [13]
つまり、石炭紀の虫が大きくなれたのは、空に敵がいなかったから、という見方もできます。
[解説] そして、アースロプレウラの、あの大きな化石の年代は、酸素がいちばん多くなる時期よりも、前でした。見つけた研究者たちは、酸素だけでは説明できず、栄養のある食べ物が豊富だったことも大きかったのではないか、と考えています。
# 画面: 推定（説が分かれている）
# 根拠: [6][3]
酸素は、おそらく理由の一つです。
けれど、それだけでは、すべてを説明できない。
いまのところ、それが正直な答えです。

# ===== 7. 森が石炭になるまで =====
[転換] では、この森は、どうやって石炭になったのでしょうか。
森の地面は、ほとんどいつも、水につかっていました。
倒れた木は、水の底に沈みます。
[解説] 水の中では、腐らせる生き物が働きにくく、枯れた植物は、分解されないまま、厚く積み重なっていきます。
# 画面: 確認
その上に、また新しい木が育ち、倒れ、積み重なる。
やがて、その層は、土や砂に埋もれ、長い時間をかけて、熱と重さで押し固められていきます。
[名前] こうしてできたのが、石炭です。
[解説] ヨーロッパや北アメリカのこの時代の石炭は、多いもので、その八割ほどが、リンボクの仲間からできています。
# 根拠: [5]
[転換] けれど、ここで一つの疑問が浮かびます。
なぜ、この時代に、これほどたくさんの石炭ができたのでしょうか。
[溜め] {二〇一二年|にせんじゅうにねん}、有名な説が発表されました。
# 根拠: [14]
木の幹には、かたくて分解されにくい成分が含まれています。
いまの森では、この成分を分解できるキノコの仲間がいて、倒れた木を土に返しています。
[解説] キノコの仲間の遺伝子を調べたところ、この成分を分解する力を持ったキノコが現れたのは、石炭紀の終わりごろだったかもしれない、という結果が出ました。
つまり、それまでは、倒れた木を分解できる生き物がいなかったので、木がたまり続けて石炭になった、という説です。
# 画面: 推定
わかりやすく、とても魅力的な説です。
[転換] ところが、{二〇一六年|にせんじゅうろくねん}、別の研究者たちが、この説に反論しました。
# 根拠: [15]
[解説] 石炭のもとになったリンボクの仲間は、幹のほとんどが樹皮で、その分解されにくい成分を、もともとあまり含んでいませんでした。また、森の主役の植物が入れ替わっても、石炭のたまり方は、ほとんど変わっていなかったのです。
[解説] この研究者たちは、赤道の湿った気候と、大陸がぶつかり合ってできた、広く沈んでいく低い土地が、石炭をたくさん生んだ、と考えています。
# 画面: 推定（説が分かれている）
どちらの考え方が正しいのか、議論は、いまも続いています。
[転換] そして、それから三億年後。
イギリスで掘り出されたこの時代の石炭が、蒸気機関を動かし、工場を動かしていきました。
# 画面: 演出（産業革命の場面は描かず、石炭の断面で表す）
あの森にたまった光が、長い時間をかけて、人間の時代を動かすことになったのです。

足元の泥が、乾いて、ひび割れています。
あれほど並んでいたリンボクの幹が、ところどころで倒れ、すき間から、強い日差しが差し込んでいます。
[解説] 南の大陸で氷が広がったり縮んだりするにつれて、赤道の気候も、湿った時期と乾いた時期をくり返すようになっていきました。
# 画面: 推定
# 根拠: [3][17]
[溜め] どこまでも続いていた湿地の森は、やがて、ばらばらに分かれ、島のように点々と残るだけになりました。
これは、石炭紀の雨林の崩壊と呼ばれています。
[解説] リンボクの仲間は、この地域の森の主役の座を降り、代わりに、木のように背の高いシダの仲間などが増えていきました。
# 根拠: [5][21]
# 画面: 確認
[転換] 森に暮らしていた動物たちにも、大きな変化が起きました。
[解説] 水辺に卵を産むカエルの遠い親戚たちは、大きな打撃を受け、一方で、乾いた陸でも卵を産める{爬虫類|ハチュウルイ}の仲間が、広がっていった。そう考える研究があります。
# 根拠: [17]
[解説] ただし、化石が見つかる場所のかたよりを補正して調べ直した研究では、四本足の動物の種類は、石炭紀の終わり近くまで、むしろ増え続けていた、という結果が出ています。大きく減ったのは、そのあと、{次|つぎ}の時代との境目でした。
# 画面: 推定（説が分かれている）
# 根拠: [18]
森の崩壊が、動物たちの歴史をどこまで変えたのか。それは、いまも研究が続いています。

# ===== 結び =====
[提示] 二億九千九百万年前、石炭紀が終わります。
# 根拠: [1]
大陸は、さらに寄り集まり、陸の内側には、乾いた土地が広がっていきます。
[解説] 石炭紀が終わるころまでに、殻のある卵を産む動物たちは、二つの道に分かれていました。
# 根拠: [19]
一つは、のちにトカゲやワニ、そして恐竜や鳥につながっていく道。
[溜め] そしてもう一つは、のちに、私たち{哺乳類|ほにゅうるい}につながっていく道です。
# 画面: 確認
[解説] 実は、ヒロノムスが見つかったあのノバスコシアの崖からは、私たちにつながる側の、最も古い化石とされるものも見つかっています。
# 根拠: [19]
あの湿った森の片すみを、あなたにつながる仲間が、もう歩いていたのです。
[転換] 次の時代、ペルム紀。
その終わりには、地球の歴史で最大とされる、大量絶滅が待っています。
# 根拠: [20]
[転換] 目を閉じて、もう一度開けてみてください。
石炭紀の森は、もうありません。
でも、その森は、黒い石になって、いまも地面の下に眠っています。
