[提示] 白亜紀の最後のころ。いまの北アメリカの西部です。
# 根拠: [33][34]
# 画面: 演出（景色は想像）
あなたは、川の流れる森のはずれにいます。
地面が、かすかに揺れました。
[名前] ティラノサウルス。
[解説] 全長は、十二メートルを超え、体重は五トン以上あったと見積もられています。
# 画面: 確認（骨格）／推定（全長と体重）
# 根拠: [26][28]
[解説] {二〇〇四年|にせんよねん}の研究は、骨に残る成長のしるしから、ティラノサウルスの育ち方を調べました。
[解説] 最も速く育つ時期には、一日に二キロあまりも体重を増やし、二十年ほどで骨が大人の体になっていました。長生きしたものは、二十八歳ほどまで生きていたとされます。
# 画面: 推定
# 根拠: [26]
[転換] そして、かむ力です。
[解説] {二〇一二年|にせんじゅうにねん}の研究は、あごの筋肉の模型をコンピューターで動かし、奥の歯一本にかかる力を、三万五千から五万七千ニュートンと見積もりました。陸の動物で見積もられた中では、飛び抜けて強い力です。
# 画面: 推定
# 根拠: [27]
[解説] ニュートンは、力の大きさの単位です。五万七千ニュートンは、およそ六トンの重さが、歯の先にのしかかるほどの力に当たります。
# 根拠: [27]
[解説] 別の研究は、ティラノサウルスが、獲物の骨まで、くり返しかみ砕いて食べていたことを示しています。
# 根拠: [28]
[転換] では、その口元は、どんな姿だったのでしょうか。
[解説] 映画などでは、大きな歯がむき出しの姿で描かれることが多いですね。
[解説] けれど、{二〇二三年|にせんにじゅうさんねん}の研究は、いまのオオトカゲなどと比べて、口を閉じたときには、歯は唇のような皮ふで隠れていた可能性が高い、と考えました。
# 画面: 推定
# 根拠: [30]
[解説] 一方で、顔の皮ふは、ワニのような、敏感なうろこに覆われていた、とする研究もあります。口元の姿は、まだ決着していません。
# 画面: 推定（説が分かれている）
# 根拠: [31]
[転換] 子どものティラノサウルスは、どう暮らしていたのでしょうか。
[解説] {二〇二一年|にせんにじゅういちねん}の研究は、巨大な肉食恐竜のいる場所には、中くらいの大きさの肉食恐竜が少ない、という傾向を見つけました。そのすき間を、育ちざかりの子どもたちが埋めていたのではないか、と考えています。
# 画面: 推定
# 根拠: [32]
[解説] ところが、{二〇二五年|にせんにじゅうごねん}に、別の研究が発表されました。
[解説] これまでティラノサウルスの子どもと考えられてきた化石の一部は、実は、ナノティラヌスという、別の恐竜だった、というのです。
# 画面: 推定（説が分かれている）
# 根拠: [33]
[解説] この研究が正しければ、ティラノサウルスの育ち方や暮らし方をめぐる、これまでの多くの考えを、見直す必要が出てきます。
